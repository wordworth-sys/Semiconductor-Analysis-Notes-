# 🔬 半导体检测与分析 (Semiconductor Analysis Notes)

欢迎来到我第一个正式仓库！这里分享的是**SDUT微电子科学与工程专业大三下学期选修课《半导体检测与分析》**的期末复习笔记与默写提纲。

这份笔记基于课堂讲解、作业题以及期末重点整理而成，参考书籍是许振嘉的《半导体的检测与分析》，简单，从定性的角度涵盖了微电子领域常见的半导体表征与检测技术。希望能帮助到正在修读这门课程的学弟学妹们，或者对半导体检测技术感兴趣的同学。开源共享，祝大家期末顺利，高分飘过！🎉

## 📂 仓库内容 (Repository Contents)

本仓库主要包含以下核心文件：

## 📖 知识点大纲 (Syllabus)

笔记完整覆盖了以下八个核心章节：

1.  **第一章**：三代半导体材料概述
2.  **第二章**：TEM 透射电子显微镜（成像原理、分辨率、放大倍率、球差消除等）
3.  **第三章**：SEM 扫描电子显微镜（成像原理、景深、衬度机制、荷电效应等）
4.  **第四章**：STM 扫描隧道显微镜（隧穿效应、恒流/恒高模式区分等）
5.  **第五章**：AFM 原子力显微镜（接触、非接触与轻敲模式原理及优缺点等）
6.  **第六章**：XPS X射线光电子能谱仪（光电离/电子弛豫过程、初态/终态效应、化学位移等）
7.  **第七章**：拉曼光谱（瑞利散射与拉曼散射能带图、拉曼光谱特征等）
8.  **第八章**：XRD X射线衍射（布拉格方程推导、衍射矢量方程、结构因子计算、系统消光解释等）

## 💡 食用指南 (How to Use)

1.  **日常学习**：结合上课进度，在线阅读 `.md` 重点笔记，GitHub 原生支持 Markdown 解析，格式清晰。
2.  **考前突击**：下载 `.pdf` 文件并打印，重点记忆公式（如布拉格方程、TEM/SEM分辨率公式）和各大显微镜的成像原理。
3.  **终极自测**：对着 `默写.md` 里的框架，尝试在草稿纸上画出能带图、写出产生衍射的充分条件、推导面心/体心晶胞的结构因子。
